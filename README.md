# Gold Price Forecasting Dataset 🪙📈

A gold price dataset prepared for financial data analysis, technical indicator exploration, and machine learning experiments.

## Project Overview

This repository contains historical gold price data along with several technical indicators that can be used for exploratory analysis and forecasting experiments.

The dataset is useful for learning how financial time-series data can be prepared and analyzed using Python.

## Dataset Features

The dataset includes:

* Date
* Adjusted Close
* Close
* High
* Low
* Open
* Volume
* 7-day Moving Average
* 30-day Moving Average
* 90-day Moving Average
* Daily Return
* 7-day Volatility
* 30-day Volatility
* RSI
* MACD
* MACD Signal
* Upper Bollinger Band
* Lower Bollinger Band
